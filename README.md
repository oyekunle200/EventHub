# EventHub Backend API

EventHub is a backend project built with Node.js, Express.js, and MongoDB for managing event bookings, users, and payments.

## Features

* User authentication
* Password reset using email OTP
* Booking management
* Payment record management
* Payment verification logic
* MongoDB database integration

## Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* JavaScript
* Nodemailer
* bcrypt
* JSON Web Token (JWT), where implemented

## Payment Integration

The project includes payment record management and backend payment verification logic. Integration with a live payment gateway is a future improvement.
